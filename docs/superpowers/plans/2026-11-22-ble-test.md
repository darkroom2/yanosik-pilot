# BLE Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal nRF52 Arduino sketch that advertises a BLE device named `nRF52_Test`.

**Architecture:** Add the BLEPeripheral dependency to the existing nRF52 PlatformIO environment and implement one Arduino entry point. The sketch starts BLE once and polls the peripheral from the Arduino loop.

**Tech Stack:** PlatformIO, Adafruit nRF52 Arduino core, Bluefruit

**Spec:** The approved request in the current conversation.

## Global Constraints

- Work only in `firmware/ble-test`.
- Use the existing `nrf52_dk` environment.
- Advertise the local and device name `nRF52_Bluefruit`.
- Do not add unit tests.
- No flash operations or direct nRF52 register access.

## Review Focus

- Dependency availability: `BLEPeripheral` must be resolved by PlatformIO before compilation.
- Startup: BLE initialization must occur before the first poll.
- Identity: both local name and device name must be `nRF52_Test`.
- Runtime: the Arduino loop must continuously poll the BLE peripheral.
- Build target: use the existing Nordic nRF52 board, not a host test environment.

### Task 1: Configure and implement BLE test firmware

**Files:**
- Modify: `firmware/ble-test/platformio.ini`
- Create: `firmware/ble-test/src/main.cpp`
- Test: Build the `nrf52_dk` environment; no unit test suite

**Interfaces:**
- Consumes: PlatformIO `nordicnrf52` environment and `BLEPeripheral` API.
- Produces: a sketch that initializes BLE and continuously polls it.

- [ ] **Step 1: Add the BLEPeripheral dependency**

Add `sandeepmistry/BLEPeripheral` to `lib_deps` under the existing `[env:nrf52_dk]` section.

- [ ] **Step 2: Create the minimal Arduino firmware**

Create `firmware/ble-test/src/main.cpp` with:
- `BLEPeripheral blePeripheral = BLEPeripheral();`
- `setup()` starting Serial at `115200`, setting local/device name to `nRF52_Test`, and calling `begin()`
- `loop()` calling `blePeripheral.poll()`

- [ ] **Step 3: Build firmware**

Run:

```powershell
uv run pio run --project-dir firmware/ble-test -e nrf52_dk
```

Expected: PlatformIO resolves the dependency and produces a successful nRF52 firmware build.
